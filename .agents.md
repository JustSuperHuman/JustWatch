# Agent Instructions for JustWatch

When working on this project, use these scripts to test your changes.

## After Making Code Changes

```bash
cd F:\JustWatch
bun run update
```

This stops the running app, rebuilds, and relaunches it. Always do this after editing any `.cs`, `.xaml`, or `.html` source files. Do not try to run the exe directly — `bun run update` handles killing the old process and waiting for file locks.

## Quick Controls

```bash
bun run stop      # Kill the tray app and watcher service
bun run start     # Launch the tray app (without rebuilding)
```

## Testing the Agent Pipeline

To test ChatSession / TaskManager changes without the UI:

```bash
dotnet run --project src/JustWatch.Test
```

Edit `src/JustWatch.Test/Program.cs` to write focused tests. The test project references Core and can exercise ChatSession, TaskManager, ScreenRecorder, etc. directly.

## Important Notes

- The tray app locks its DLLs while running — you MUST stop it before rebuilding
- `bun run update` handles this automatically, `dotnet build` alone will fail if the app is running
- WebView2 spawns `msedgewebview2.exe` processes that can also hold locks — `bun run update` kills these too
- The watcher service install requires admin — run the terminal as Administrator for that step
- Config is at `config/justwatch-config.json` — changes take effect on next app restart
- Recordings go to `%USERPROFILE%\Videos\JustGains Tests\`
